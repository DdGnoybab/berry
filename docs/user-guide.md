# Berry 使用指南

> Berry 帮你**为面试 / 深度掌握**学习一个技术主题(redis / 操作系统 / 计网...)。
> 它会陪你走完整个学习闭环:摸底 → 给路线图 → 一题一题讲 / 测 → 巩固。

## 30 秒快速上手

1. 浏览器打开你的 Berry 地址
2. 用账号密码登录
3. 左上 **`+ NEW TOPIC`** 创建一个学习主题(填要学什么、目标是什么)
4. 等 Berry 给出**学习路线图**(几个模块,每模块几个原子知识点)
5. 跟 Berry 对话学习,**输入文字回答问题**(不要等按钮)

---

## 核心概念

```
你的账号
  │
  ├── Topic (主题): redis / 操作系统 / DDD / ...
  │     ├── ROADMAP: 7 个模块 × 4-6 个原子知识点
  │     ├── 进度: 当前在哪个模块的哪个 atom
  │     └── Sessions: 跟这个 topic 有关的多次对话
  │           ├── Session #1 (今天上午)
  │           ├── Session #2 (今天下午)
  │           └── ...
  │
  └── Topic (另一个主题)
        └── ...
```

- **Topic** 一旦建好,**进度跟着 topic 走**,不是跟着 session 走
- 关电脑明天再上来,新建 session 接着原 topic 继续,Berry 会"恢复你上次到哪了"
- 同一 topic 下可以有多个 session(分多次学)

## 一、新建一个学习主题

点左上角 **`+ NEW TOPIC`** 弹出表单:

| 字段 | 怎么填 | 示例 |
|---|---|---|
| Name | 短 slug,**英文小写** | `redis` `os` `ddd` |
| Title | 中文标题(可选) | `Redis 学习` |
| Goal | 学习目标(影响 Berry 讲解深度) | `面试准备` / `深度掌握` |

确认后 Berry 会:

1. 调模型生成 ROADMAP(模块和原子知识点列表)
2. 弹欢迎卡片,问你"想从哪开始"
3. 你可以**直接回答**(不一定要点按钮),例:
   - 「按顺序来」
   - 「先看完整路线图」
   - 「直接从模块 03 开始」

## 二、学习循环

每个原子知识点(atom)走这个闭环:

```
PROBING (摸底)        Berry 出几道题先看你水平
   │
   ▼
TEACHING (讲解)       根据你的水平讲清楚
   │
   ▼
ASSESSMENT (测试)     再出 1-3 题看你是不是真懂了
   │
   ├─ 答对 → 推进到下一个 atom
   └─ 答错 → 回到 TEACHING 换角度再讲
```

### 你能说什么

- **回答题目** → 直接打字
- **跳过这块** → 「这个我会了,跳过」
- **细节深入** → 「展开讲讲 XXX」
- **看路线图** → 「看一下完整路线图」
- **看进度** → 「我学到哪了」
- **换 atom** → 「我想先学持久化」

Berry 会在心里跟踪你的状态(`.berry/progress.json`),你不需要管。

### 关于"按钮"

Berry 偶尔会渲染选项按钮(快捷选项),但**任何时候你都可以打字回答**,不必点按钮。
按钮只是为了快,文字交互才是主路径。

## 三、跳过 / 推进 / 重置

### 跳过模块或原子

如果你已经掌握了某些知识点,告诉 Berry:

> 「模块 01 (概述)和模块 02 (数据类型)我都熟,跳过,直接进模块 03 持久化」

Berry 会:
1. 把模块 01、02 标 `skipped`(算作完成,**进度条会前进**)
2. 把当前游标跳到模块 03 的第一个 atom
3. 继续 PROBING(因为它不知道你模块 03 水平)

### 重置某个 topic

侧边栏底部 **`⚠ RESET CURRENT`** 按钮:

- 清空当前 topic 的所有 session、所有进度、workspace 文件
- ROADMAP 重新生成(模型可能生成的不完全一样)
- **不可恢复**,确认前会弹二次确认

适合"路线图我不满意,重来一遍"。

### 删除 topic

主题卡片右上角的 `[/]` 图标 → 二次确认 → 整个 topic 永久删除。

## 四、Session(对话)

Session 是"一次坐下来跟 Berry 聊"的会话单元。

| 操作 | 怎么做 |
|---|---|
| 看历史 session | 点开主题卡片,下面会展开列出该 topic 全部 session |
| 切换 session | 点列表里的 session 行 |
| 新建 session | session 列表底部 **`+ NEW SESSION`** |
| 删除 session | session 行右侧 `×` 按钮 |

**关键点**:
- 新建 session 时 Berry 会**自动恢复进度**,问你"接下来想干嘛"(可能给你 3-4 个选项)
- 删完一个 topic 的最后一个 session,Berry 会自动给你建一个新的,不至于无 session 卡死

## 五、记忆(Berry 记得你)

Berry 会在对话过程中**自动记住**:

- 你的偏好("我喜欢先听讲解再做题")
- 项目事实("用户跳过了 redis 模块 02")
- 角色背景(你在 LEARNER.md 里写的)

下次对话,这些内容会自动注入提示词,Berry 不会"失忆"。

如果你发现 Berry 记错了什么,可以**直接告诉它纠正**:

> 「忘掉你之前说的 X,现在情况是 Y」

它会调用 memory 工具更新这条记忆。

## 六、常见困惑

### 我在飞书也能用吗?

可以。同一个账号绑定后,飞书里 @机器人 一句,会跟 Web 用同一个 agent。
**进度跨设备同步**(因为进度在服务器上,不在浏览器本地)。

### 我打字它没反应?

刷新一下页面。如果还是不行,看右上角是不是显示 "SIGN OUT" —— 在线说明登录还有效。

### 它给我的代码 / 命令能直接复制吗?

代码块右上角有"复制"按钮(悬停可见)。粘贴到本地终端跑就行。

### 它会自动跑命令吗?

**不会**。Berry 不会在你电脑上跑任何命令。你要自己复制粘贴执行。
(如果你看到它在"调工具",那是它在 berry 服务器自己的沙箱里跑,跟你电脑无关。)

### 我中断对话回来,它会从头讲吗?

不会。它读 `.berry/progress.json` 知道当前 atom + state(摸底中 / 讲解中 / 测试中),
直接从那一刻往下走。

(只有 role=admin 的账号能看到的地方)

- **左侧 sidebar 底部 `▤ ADMIN · LOGS`**:进 `/admin/logs` 看后端日志,出问题时复盘用
- 日志使用文档:`/admin/logs` 页面右上角 `?` 按钮

## 反馈

写不下去 / Berry 卡住 / 体验不顺,直接告诉运维(用 admin 账号 ssh 上服务器或在源码 repo 提 issue)。
日志会替你记得发生了什么,不用截图(但截图有助于定位 UI bug)。
